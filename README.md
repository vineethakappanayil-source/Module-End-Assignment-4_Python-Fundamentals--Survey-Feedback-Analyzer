# Module-End-Assignment-4_Python-Fundamentals--Survey-Feedback-Analyzer


A beginner-friendly Python project that collects and analyzes customer survey feedback. It demonstrates core Python skills, including dictionaries, loops, conditionals, string cleaning, functions, and sorting.

## Project contents

- [Jupyter Notebook](Module%20End%20Assignment%204_Python%20Fundamentals%20Survey%20Feedback%20Analyzer.ipynb) - the completed Python assignment.
- [Assignment PDF](Module%20End%20Assignment%204_Python%20Fundamentals-%20Survey%20Feedback%20Analyzer.pdf) - the project requirements.

## What the program does

- Starts with 10 sample feedback entries and lets the user add more.
- Assigns serial numbers to new entries, starting at 11.
- Cleans feedback by removing punctuation, extra spaces, and uppercase letters.
- Counts feedback containing the words `good`, `poor`, and `excellent`.
- Displays the average rating, longest comment, and unique words.
- Sorts feedback by rating from highest to lowest.

## How to run

1. Open the Jupyter Notebook in Jupyter Notebook, JupyterLab, or Google Colab.
2. Run the cells from top to bottom.
3. Enter the number of feedback entries to add and provide the requested details.

The notebook uses Python 3 and does not require additional packages.
